# ✈️ Squadron Flight Log Analyst

A lightweight, high-precision Java command-line application built to process tactical aviation metrics. This program analyzes post-sortie telemetry data for an active fighter squadron to optimize fuel management and isolate mechanical anomalies.

## 🚀 Core Features
*   **Squadron Telemetry Ingestion:** Processes multi-node real-time data inputs using Java array mapping.
*   **Macro-Efficiency Calculations:** Computes collective mission fuel metrics and mathematical fleet averages.
*   **Predictive Maintenance Flags:** Automatically detects outlier fuel burn rates to trigger inspections for potential fuel leaks or turbine inefficiencies.

## 🛠️ Technical Stack
*   **Language:** Java (JDK 11+)
*   **Environment:** Visual Studio Code
*   **Key Concepts:** Linear array structures, conditional execution loops, terminal string tokenization.

## 💻 How To Run
1. Clone this repository to your local machine.
2. Open your terminal and compile the application:
   ```bash
   javac SquadronLog.java
   ```
3. Run the compiled bytecode:
   ```bash
   java SquadronLog
   ```
